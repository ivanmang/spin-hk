# 轉一轉

香港人嘅決定盤。今晚食咩、放學後去邊、拍拖送咩，轉一下就得。

**Live site:** [https://ivanmang.github.io/spin-hk/](https://ivanmang.github.io/spin-hk/)

單檔靜態頁，無需伺服器。開頁、撲主題、轉盤。

自己加選項、洗牌、或者用連結分享同一個轉盤。

## 用法

- 撲右邊主題 chips 載入一套選項
- 撲「轉盤」，或者空白鍵
- 複製連結，朋友開同一個盤
- 「轉完刪走呢個」＝淘汰賽
- 「加大格機會高啲」＝權重

選項存在瀏覽器 `localStorage`，唔會上傳。
