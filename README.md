# Spin / 轉一轉

A decision wheel for everyday Hong Kong choices.

**Live:** https://ivanmang.github.io/spin-hk/

**English:** https://ivanmang.github.io/spin-hk/?lang=en

Use **中 / EN** in the header to switch language. Themes and options follow.

Toolbar buttons are icons: help, sound, share, and fullscreen.

## How to use

1. Pick a theme, or type a short prompt to generate options.
2. Add, edit or delete options. The wheel needs at least two.
3. Tap **Spin**, or press the space bar.
4. Bookmark saves a custom wheel under Custom.
5. Copy the link icon to share the same wheel.

Options, history and settings stay in this browser. No account is created.
