# 轉一轉 / Spin

隨機轉盤，協助您從多個選項中作出決定。可按 **中 / EN** 切換語言。

A decision wheel for everyday Hong Kong choices. Switch language with **中 / EN**.

**網站：** [https://ivanmang.github.io/spin-hk/](https://ivanmang.github.io/spin-hk/)  
**English:** [https://ivanmang.github.io/spin-hk/?lang=en](https://ivanmang.github.io/spin-hk/?lang=en)

## 使用方法

1. 選擇主題，或輸入簡短提示以產生選項。
2. 可新增、編輯或刪除選項。轉盤須至少包含兩個選項。
3. 按「開始轉動」，亦可使用鍵盤空白鍵。
4. 如需進行淘汰，請開啟「抽出後移除該選項」。
5. 如需提高指定選項被抽出的機會，請開啟「調整權重」。
6. 按書籤圖示儲存轉盤；之後可於「自訂」分類載入。
7. 按連結圖示複製分享網址，以便他人開啟同一轉盤。

應用程式右上角的問號圖示，亦可開啟相同說明。

工具列使用圖示：使用說明、聲音、分享連結、全螢幕。

## How to use

1. Pick a theme, or type a short prompt to generate options.
2. Add, edit or delete options. The wheel needs at least two.
3. Tap **Spin**, or press the space bar.
4. Turn on “Remove the winner after a spin” for elimination rounds.
5. Turn on “Adjust weights” to make some options more likely.
6. Tap the bookmark to save a wheel, then reopen it under Custom.
7. Tap the link icon to copy a share URL for the same wheel.

The question-mark icon in the toolbar opens the same guide.

Toolbar buttons use icons (help, sound, share, fullscreen), not text labels.

## 功能 / Features

- 預設主題涵蓋日常、工作、外出、學習、約會與聚會  
  Everyday Hong Kong themes: food, work, going out, school, dates, hangouts
- 以文字提示產生選項  
  Generate options from a short prompt
- 自訂選項、圖示、權重與淘汰模式  
  Custom options, icons, weights, and elimination mode
- 儲存常用轉盤，並可透過連結分享  
  Save wheels and share them with a link
- 最近結果記錄  
  Recent results

## 資料儲存 / Data

選項、記錄與設定均儲存於本裝置的瀏覽器，不會建立帳戶。產生選項時，系統只會傳送您輸入的提示。

Options, history and settings stay in this browser. No account is created. When generating options, only the prompt you type is sent.
